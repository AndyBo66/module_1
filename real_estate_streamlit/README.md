# Прогнозирование стоимости недвижимости — Streamlit

Учебный проект: модель машинного обучения оценивает стоимость недвижимости по характеристикам объекта.
Интерфейс создан на Streamlit.

## Структура проекта

```text
real_estate_streamlit/
├── data/
│   └── realty_data.csv
├── model/
│   ├── real_estate_model.joblib   # создаётся после обучения
│   └── model_info.json            # создаётся после обучения
├── train.py
├── app.py
├── requirements.txt
└── README.md
```

## Требования

- Python 3.10 или новее
- Интернет для первоначальной установки библиотек

## Установка и запуск (Windows)

Открыть терминал в папке проекта и выполнить:

```bash
python -m venv venv
venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Обучение модели

```bash
python train.py
```

Скрипт загружает `data/realty_data.csv`, обрабатывает пропуски, обучает RandomForestRegressor, выводит MAE и R² и сохраняет модель и метаданные в папку `model/`.

Если модель уже обучена и оба файла в `model/` присутствуют, этот шаг можно пропустить.

## Запуск интерфейса

```bash
streamlit run app.py
```

Streamlit обычно откроет приложение в браузере автоматически. Если этого не произошло, открыть адрес, указанный в терминале (обычно http://localhost:8501).

## Использование

1. Ввести площадь, количество комнат, этаж и координаты.
2. Выбрать\ввести город, район, населённый пункт, тип объекта и источник объявления.
3. Нажмите **«Рассчитать стоимость»**.
4. Приложение покажет прогноз в рублях.

## Метрики

После обучения скрипт выводит:
- **MAE** — средняя абсолютная ошибка прогноза в рублях; меньше — лучше.
- **R²** — коэффициент детерминации; ближе к 1 — лучше.

Фактические значения метрик зависят от версии библиотек и разбиения данных; использовать результаты, напечатанные при запуске `train.py`.

## Примечание

Прогноз является оценкой модели по старым объявлениям и не заменяет профессиональную оценку недвижимости.
